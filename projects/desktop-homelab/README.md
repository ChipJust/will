# Desktop Homelab

Convert the existing desktop (i9-9960X, 128GB RAM, X299) from Windows 10 into a Linux-based personal home server. Replace Windows with Ubuntu 24.04, expose existing storage as family-shared NAS, host a music streaming service for the household, and run Claude Code as a long-running session reachable from phone and laptop. No Microsoft services in the loop.
